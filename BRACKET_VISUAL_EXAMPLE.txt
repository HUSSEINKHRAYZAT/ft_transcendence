┌──────────────────────────────────────────────────────────────────────┐
│                      BACKEND COORDINATION                            │
└──────────────────────────────────────────────────────────────────────┘

Frontend polls tournament state every 3 seconds:
1. Fetch latest tournament data from backend
2. Check all match statuses
3. Render updated bracket
4. Look for active match with current player
5. If found → Transition to "Start Next Match" screen
6. If tournament complete → Show winner screen

┌──────────────────────────────────────────────────────────────────────┐
│                         MATH CALCULATIONS                            │
└──────────────────────────────────────────────────────────────────────┘

Tournament Size → Rounds:
• 4 players  → 2 rounds (Semifinals → Final)
• 8 players  → 3 rounds (Quarterfinals → Semifinals → Final)
• 16 players → 4 rounds (Round of 16 → Quarters → Semis → Final)

Matches per Round:
• Round 1: size / 2 matches
• Round 2: size / 4 matches
• Round 3: size / 8 matches
• Final: Always 1 match

Example 8-player tournament:
• Round 1: 4 matches (8 players)
• Semifinals: 2 matches (4 winners)
• Final: 1 match (2 winners)
• Total: 7 matches to determine champion
